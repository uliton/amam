# am-am 🍼

Легкий React-застосунок для сімейного щоденника годувань 🍼. React + Vite, без UI-фреймворків. Адаптивний український інтерфейс.

## Локальний запуск

```sh
npm ci
cp .env.example .env
npm run dev
```

У `.env` вкажіть `VITE_API_URL` (адреса API з `/api`). Сімейний код вводиться через «Маю код» та обмінюється на сесію; підключені родини зберігаються на пристрої; його не можна додавати до Vite-змінних чи репозиторію. Стартовий екран пропонує демо, створення родини й вхід за кодом. Без API працює демо. Демо-дані ніколи не відправляються на сервер.

## Можливості

- Годинник та вибір UTC-зсуву (зміна літнього/зимового часу вручну).
- Час від останнього годування для кожної дитини, включно із записами поза останніми 30 днями.
- Пляшечка 30–300 мл; з’їдений об’єм 0–об’єм пляшечки з кроком 1 мл, кнопки ±5 мл; зригування.
- Дата і час годування, редагування записів, підтвердження лише після відповіді сервера.
- Підсумки за сьогодні, графік і журнал за сьогодні/7/30 днів, фільтр дитини.
- Автооновлення кожні 30 секунд, поки сторінка видима.
- Іконки з пляшечкою для вкладок, iPhone/iPad та Android; відкриття з початкового екрана в окремому вікні. PNG вже включені в репозиторій; відтворити на macOS: `swift scripts/generate-icons.swift public`.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` збирає та публікує фронтенд після push у `main`.
У Settings → Pages → Source виберіть **GitHub Actions**. URL: `https://uliton.github.io/amam/`.
Адреса API за замовчуванням: `https://kolir.in:8443/api`; її можна змінити через Repository variable `VITE_API_URL`.
Production base `/amam/` встановлюється під час GitHub Actions; локально використовується `/`.

```sh
npm run build
npm run preview
```

MongoDB та її облікові дані знаходяться виключно на бекенді. Публічний репозиторій містить лише фронтенд.

## Локальна перевірка нового інтерфейсу

`npm run review` запускає демо-перегляд із примусово відключеним API та окремим локальним сховищем. Робочі записи й сімейний код не використовуються. Адресу покаже Vite; якщо 5173 зайнятий, буде наступний вільний порт.

Видалення годування переносить його в кошик: воно не входить у статистику й доступне для відновлення. Для цього потрібен сумісний API з маршрутами кошика. Маршрути кошика захищені тим самим сімейним кодом.

## Родини (локальна нова версія)

Майстер створення родини, ім’я/емодзі/палітра дітей, постійні коди власника/внесення годувань/перегляду. Підключення пристрою безстрокове: код вводиться один раз. Перемикач кількох родин у хедері. Зміни й архів зберігають childId та історію. CSV-експорт за період, імпорт власником із зіставленням дітей; автоматична тема (світла 07:00–21:00, темна 21:00–07:00 за часом пристрою) та збережений ручний вибір. Сон — пізніше.

`npm run families-review` відкриває окремий режим на http://127.0.0.1:5175/ з **виключно локальним** API http://127.0.0.1:4311/api. Запустіть `npm run review` у сусідній папці back: це тестовий сервер із локальним сховищем, без .env та MongoDB. Тестові родини зберігаються локально в back/review-data/, поза Git. Звичайний `npm run review` залишається без API.

Коди/сесії не додавайте до Git, адреси API чи Vite env. Власник може зберегти картку кодів SVG. Картка й локальне сховище підключеного пристрою є секретними. Запрошення editor/viewer передають код у фрагменті, який одразу прибирається й обмінюється на сесію; код власника у посилання не додається.

`node --test test/*.test.js` перевіряє CSV; серверні рольові тести запускаються в back через npm test. Для продакшну потрібен новий сумісний API: спочатку бекенд із розмежуванням родин, потім фронт.
