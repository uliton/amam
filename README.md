# am-am 🍼

Легкий React-застосунок для щоденника годувань Леона 🦁 та Луки 🐻. React + Vite, без UI-фреймворків. Адаптивний український інтерфейс.

## Локальний запуск

```sh
npm ci
cp .env.example .env
npm run dev
```

У `.env` вкажіть `VITE_API_URL` (адреса API з `/api`). Сімейний код вводиться через «Наша родина» і зберігається тільки в браузері; його не можна додавати до Vite-змінних чи репозиторію. Без налаштованого API застосунок відкривається в явно позначеному демо-режимі. Демо-дані ніколи не відправляються на сервер.

## Можливості

- Годинник та вибір UTC-зсуву (зміна літнього/зимового часу вручну).
- Час від останнього годування для кожної дитини, включно із записами поза останніми 30 днями.
- Пляшечка 30–300 мл; з’їдений об’єм 0–об’єм пляшечки з кроком 1 мл, кнопки ±5 мл; зригування.
- Дата і час годування, редагування записів, підтвердження лише після відповіді сервера.
- Підсумки за сьогодні, графік і журнал за сьогодні/7/30 днів, фільтр дитини.
- Автооновлення кожні 30 секунд, поки сторінка видима.
- Іконки з пляшечкою для вкладок, iPhone/iPad та Android; відкриття з початкового екрана в окремому вікні. PNG вже включені в репозиторій; відтворити на macOS: `swift scripts/generate-icons.swift public`.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` збирає та публікує фронтенд після push у `main`.
У Settings → Pages → Source виберіть **GitHub Actions**. URL: `https://uliton.github.io/amam/`.
Адреса API за замовчуванням: `https://kolir.in:8443/api`; її можна змінити через Repository variable `VITE_API_URL`.
Production base `/amam/` встановлюється під час GitHub Actions; локально використовується `/`.

```sh
npm run build
npm run preview
```

MongoDB та її облікові дані знаходяться виключно на бекенді. Публічний репозиторій містить лише фронтенд.

## Локальна перевірка нового інтерфейсу

`npm run review` запускає демо-перегляд із примусово відключеним API та окремим локальним сховищем. Робочі записи й сімейний код не використовуються. Адресу покаже Vite; якщо 5173 зайнятий, буде наступний вільний порт.

Видалення годування переносить його в кошик: воно не входить у статистику й доступне для відновлення. Для цього потрібен сумісний API з маршрутами кошика. Маршрути кошика захищені тим самим сімейним кодом.
